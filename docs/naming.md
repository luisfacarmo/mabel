# Why "Mabel"?

> *"Because some mysteries are best solved in silence."*

## The Reference

**Mabel Mora** is the protagonist of *Only Murders in the Building* (Selena Gomez) — a designer obsessed with true crime who solves mysteries while always wearing her headphones.

## Why it works

| Aspect | Connection |
|--------|-----------|
| Headphones | Mabel Mora always has headphones on — it's her most recognizable visual trait |
| Investigation | The project "investigates" the Soundcore Bluetooth protocol (reverse engineering) |
| Silence | Active Noise Cancelling = the silence Mabel uses to focus |
| Design | Mabel is a designer/artist — the project focuses on a premium UI |
| Solo | Mabel works alone before finding partners — personal one-person project |
| Mystery | Proprietary Bluetooth protocol = mystery to solve |

## Selection criteria

- Short (5 letters)
- Easy to pronounce in any language
- Not taken on crates.io or npm
- Available as GitHub repo (`luisfacarmo/mabel`)
- Has personality (not generic like "Soundcore Desktop")
- Natural tagline: *"Because some mysteries are best solved in silence."*

## Alternatives discarded

| Name | Reason |
|------|--------|
| soundcore-desktop | Generic, no personality |
| anker-companion | Potential trademark issues |
| openscq-desktop | Confusing with OpenSCQ30 (different project) |
| silencer | Too aggressive |
| hush | Already exists in another context |
